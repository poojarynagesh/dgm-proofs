1. The autoregressive (chain-rule) factorisation is exact

Statement

For any joint distribution over a sequence, $p(x_1,\ldots,x_T)=\prod_{t=1}^{T}p(x_t\mid x_{<t})$ — no independence assumption is made, so modelling each conditional loses nothing; and sampling the conditionals left to right produces exact samples of the joint. (Oct 17 notes §9.3–9.4, recapped Oct 24 §2.1.) Used later in: the teacher-forcing loss (proof 12), decoding (proof 13), and the policy-gradient view of LLMs.

Proof of the factorisation

  1. definition of conditional probability For events $A,B$ with $p(B)>0$: $$p(A\mid B)=\frac{p(A,B)}{p(B)}\quad\Longrightarrow\quad p(A,B)=p(B)\,p(A\mid B).$$
  2. apply with $A=x_t$, $B=x_{<t}$ For every $t\ge 2$: $$p(x_1,\ldots,x_t)=p(x_{<t})\;p(x_t\mid x_{<t}).$$ For $t=1$ the context is empty, so $p(x_1)=p(x_1\mid x_{<1})$.
  3. induction on $T$ Base: $p(x_1)=p(x_1\mid x_{<1})$. Step: assume $p(x_{<T})=\prod_{t=1}^{T-1}p(x_t\mid x_{<t})$; insert into step 2 with $t=T$: $$p(x_1,\ldots,x_T)=\Big[\prod_{t=1}^{T-1}p(x_t\mid x_{<t})\Big]\,p(x_T\mid x_{<T})=\prod_{t=1}^{T}p(x_t\mid x_{<t}).$$
  4. log is monotone, log of product = sum of logs $$\log p_\theta(x_1,\ldots,x_T)=\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t}).$$ This is the quantity maximised in training (proof 12).
▪

Any choice of conditionals defines a valid joint, and sampling is exact step filled in — not written out in class

  1. sum out the last token first If each $p_\theta(x_t\mid x_{<t})$ is a normalised distribution over the vocabulary, then $$\sum_{x_T}\prod_{t=1}^{T}p_\theta(x_t\mid x_{<t})=\Big[\prod_{t=1}^{T-1}p_\theta(x_t\mid x_{<t})\Big]\underbrace{\sum_{x_T}p_\theta(x_T\mid x_{<T})}_{=1}.$$
  2. repeat for $x_{T-1},\ldots,x_1$ The sum over all sequences equals $1$, so the product is a proper joint distribution for any normalised conditionals — the network only has to output a softmax at each position.
  3. ancestral sampling Sample $x_1\sim p_\theta(x_1)$, then $x_2\sim p_\theta(x_2\mid x_1)$, ..., $x_T\sim p_\theta(x_T\mid x_{<T})$. The probability of producing the particular sequence $(x_1,\ldots,x_T)$ is the product of the probabilities of each draw, i.e. exactly $\prod_t p_\theta(x_t\mid x_{<t})=p_\theta(x_1,\ldots,x_T)$.
▪
Worked numeric check

Two binary tokens with joint $p(0,0)=0.3,\ p(0,1)=0.1,\ p(1,0)=0.2,\ p(1,1)=0.4$. Marginal $p(x_1=0)=0.3+0.1=0.4$. Conditional $p(x_2=1\mid x_1=0)=0.1/0.4=0.25$. Product: $0.4\times0.25=0.1=p(0,1)$ as required. Likewise $p(x_1=1)=0.6$, $p(x_2=1\mid x_1=1)=0.4/0.6=2/3$, and $0.6\cdot\tfrac23=0.4=p(1,1)$. Normalisation: $0.4(0.75+0.25)+0.6(\tfrac13+\tfrac23)=1$.

Remember for the exam
  • $x_1,\ldots,x_T$ are positions within one sequence, not different data examples (the professor stressed the change of notation). A sequence is a $T\times D$ matrix.
  • The first factor is $p(x_1)$ — empty context. The factorisation is exact (chain rule), not an approximation; the modelling choice is how to parameterise each conditional (linear / MLP / RNN / attention).
  • Log turns the product into a sum, which is what makes maximum-likelihood training a sum of per-token losses.
  • History (Oct 17): linear prediction coding $x_t\approx\sum_j a_jx_{t-j}+\epsilon_t$ (speech/telephony), Bengio-style neural LMs (MLP on past tokens; naive version ignores order), RNNs $h_t=f_\theta(h_{t-1},x_{t-1})$, $y_t=g_\phi(h_t)$ with parameters shared across time.
Common mistake

Saying the factorisation "assumes" the Markov property or conditional independence. It does not; $p(x_t\mid x_{<t})$ conditions on the whole past. Markov would be $p(x_t\mid x_{t-1})$, a special (restricted) model.

2. Why recurrence loses long-range gradient and attention does not

Statement

In an RNN the gradient from step $T$ to step $1$ is a product of $T-1$ Jacobians, which is bounded by $c^{T-1}$ and vanishes if each factor has norm at most $c<1$. With attention the context vector is a direct weighted sum, so the path from any source position to the output has length $1$. (Oct 17 notes §10.4, §11.2–11.3.) Used later in: the motivation for the Transformer, which drops recurrence.

The vanishing-gradient bound

  1. recurrence $h_t=f_\theta(h_{t-1},x_{t-1})$ with the same $\theta$ at every step (parameter sharing across time). Write the one-step Jacobian $J_t=\dfrac{\partial h_t}{\partial h_{t-1}}$.
  2. chain rule through the time steps $$\frac{\partial h_T}{\partial h_1}=\frac{\partial h_T}{\partial h_{T-1}}\cdots\frac{\partial h_2}{\partial h_1}=\prod_{t=2}^{T}J_t.$$
  3. operator norm is submultiplicative: $\|AB\|\le\|A\|\|B\|$ $$\Big\|\frac{\partial h_T}{\partial h_1}\Big\|\le\prod_{t=2}^{T}\|J_t\|.$$
  4. assume $\|J_t\|\le c<1$ (the lecture: "magnitudes below one in relevant directions") $$\Big\|\frac{\partial h_T}{\partial h_1}\Big\|\le c^{\,T-1}\xrightarrow[T\to\infty]{}0.$$ Any loss term at step $T$ therefore sends an exponentially weak signal to the early inputs: long contexts cannot be learned.
▪

Attention removes the bottleneck and the long path

  1. encoder-decoder with a single state A basic RNN encoder-decoder passes only $h_T$ to the decoder, so $h_T$ must summarise the whole input (bottleneck).
  2. keep all encoder states Form a context vector for decoder step $t$: $$c_t=\sum_{j=1}^{T}\alpha_{t,j}\,h_j,\qquad\alpha_{t,j}\ge0,\ \ \sum_j\alpha_{t,j}=1.$$
  3. differentiate $\dfrac{\partial c_t}{\partial h_j}=\alpha_{t,j}I$ — a single scalar-times-identity factor, independent of how far apart $t$ and $j$ are. (Self-attention in the Transformer uses the same idea with $z_i=\sum_j\alpha_{ij}v_j$, proof 3.)
▪
Worked numeric check

With $c=0.8$: $0.8^{49}=1.78\times10^{-5}$ for a 50-token context and $0.8^{99}=2.5\times10^{-10}$ for 100 tokens. For a context of a million tokens the bound is $0.8^{10^6}$, numerically zero. With attention the gradient factor from any position to the output is $\alpha_{ij}$ itself, for example $0.665$ in the example of proof 3, whatever the distance.

Remember for the exam
  • The Transformer paper did not invent attention; attention already existed on top of RNN encoder-decoders (translation). Its change was removing recurrence and using attention plus feed-forward layers ("Attention Is All You Need").
  • Mechanism of vanishing gradients: repeated Jacobian products with norm below one; bottleneck: one final state $h_T$ for the whole sentence.
  • RNN/GRU/LSTM share the same state-update foundation; parameters are shared across time so any length works.
Common mistake

The bound $c^{T-1}$ is a sufficient condition for vanishing, not a theorem that every RNN vanishes: if the Jacobians have norm above one the product can instead explode. The lecture phrased it as "below one in relevant directions".

3. Attention is a soft lookup: a convex combination of values

Statement

Replace a hard dictionary lookup (return the value of the best-matching key) by a differentiable one: scores $s_{ij}=q_i^\top k_j$, softmax weights $\alpha_{ij}$, output $z_i=\sum_j\alpha_{ij}v_j$. The weights are positive and sum to $1$, hence $z_i$ lies in the convex hull of the values, and in matrix form $Z=\operatorname{softmax}(QK^\top/\sqrt{d_k})V$. (Oct 17 notes §12.2–12.6; Oct 24 §2.2.) Used later in: causal attention (proof 5), multi-head attention (proof 7).

Derivation

  1. hard lookup is not differentiable A dictionary returns $z_i=v_{j^\star}$ with $j^\star=\arg\max_j q_i^\top k_j$. The argmax is piecewise constant, so no gradient reaches $W_Q,W_K$. We want a smooth surrogate.
  2. learned projections (Oct 17 §12.2) $$Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V,$$ so row $i$ gives $q_i,k_i,v_i$ for token $i$; all three are still length-$T$ sequences.
  3. similarity = inner product $s_{ij}=q_i^\top k_j$; with scaling (proof 4) $s_{ij}/\sqrt{d_k}$.
  4. softmax turns scores into weights $$\alpha_{ij}=\frac{\exp(s_{ij}/\sqrt{d_k})}{\sum_{r=1}^{T}\exp(s_{ir}/\sqrt{d_k})}.$$
  5. exp is strictly positive; dividing by the sum normalises $$\alpha_{ij}>0,\qquad \sum_{j=1}^{T}\alpha_{ij}=\frac{\sum_j\exp(s_{ij}/\sqrt{d_k})}{\sum_r\exp(s_{ir}/\sqrt{d_k})}=1.$$ Hence $0<\alpha_{ij}<1$ when $T\ge2$.
  6. weighted sum of the values $z_i=\sum_{j=1}^{T}\alpha_{ij}v_j$. By step 5 this is a convex combination of $v_1,\ldots,v_T$.
  7. convex combination stays inside the range (step filled in — not written out in class) For each coordinate $c$: $$\min_j v_{jc}=\sum_j\alpha_{ij}\min_r v_{rc}\le z_{ic}=\sum_j\alpha_{ij}v_{jc}\le\sum_j\alpha_{ij}\max_r v_{rc}=\max_j v_{jc}.$$ Attention can only mix existing values, never create a value outside their span.
  8. stack the rows $A=\operatorname{softmax}_{\text{row}}(QK^\top/\sqrt{d_k})\in\mathbb R^{T\times T}$, $Z=AV$, i.e. $$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)V.$$
  9. recover the hard lookup as a limit (extra) If one score exceeds all others by a gap $g\to\infty$, then $\alpha_{ij^\star}\to1$ and $z_i\to v_{j^\star}$: the dictionary lookup is the zero-temperature limit.
▪
Worked numeric check (lecture example, then a full 3-token example)

(a) Lecture example. Scaled scores $[2,1,0]$: $e^2=7.389,\ e^1=2.718,\ e^0=1$, sum $11.107$; weights $[0.665,0.245,0.090]$, so $z_i\approx0.665v_1+0.245v_2+0.090v_3$. The first value dominates because its key has the highest score.

(b) Full example (our own numbers, $d_k=2$): $Q=K=\begin{pmatrix}1&0\\0&1\\1&1\end{pmatrix}$, $V=\begin{pmatrix}1&0\\0&2\\3&1\end{pmatrix}$.

Remember for the exam
  • Learnable: $W_Q,W_K,W_V$. $Q,K\in\mathbb R^{T\times d_k}$ (the same width), $V\in\mathbb R^{T\times d_v}$ ($d_v$ may differ from $d_k$). Output $Z\in\mathbb R^{T\times d_v}$.
  • Why a separate value? $q\cdot k$ gives a scalar weight; you need a vector of content to mix. A simplified variant could weight the inputs $x_j$ directly, so $W_V$ is a flexible choice, not a necessity. The names query/key/value are only intuition; the lecturer stressed they are just three learned projections.
  • The inner product is a learned similarity score, not a calibrated probability; the softmax weights are the normalised attention.
  • Softmax is the only nonlinearity in attention; projections and sums are linear (used in proof 8).
Common mistake

Softmax over the wrong axis. The softmax is taken row-wise (over the keys $j$ for each fixed query $i$), so each row of $A$ sums to 1 — columns need not.

4. Why divide by the square root of the key dimension

Statement

If the components of $q$ and $k$ are independent with mean $0$ and variance $1$, then $\operatorname{Var}(q^\top k)=d_k$, so the standard deviation grows like $\sqrt{d_k}$; dividing by $\sqrt{d_k}$ restores unit variance and keeps the softmax out of its saturated, zero-gradient regime. (Oct 17 notes §12.3 gave the verbal reason; the variance computation is the standard argument, filled in.) Used later in: every attention layer, including multi-head (proof 7).

Variance of the dot product step filled in — not written out in class

  1. assumption $q_m,k_m$ ($m=1,\ldots,d_k$) are independent, $\mathbb E[q_m]=\mathbb E[k_m]=0$, $\operatorname{Var}(q_m)=\operatorname{Var}(k_m)=1$. Then $\mathbb E[q_m^2]=\mathbb E[k_m^2]=1$.
  2. expand the dot product $$q^\top k=\sum_{m=1}^{d_k}q_mk_m.$$
  3. independence of $q_m,k_m$ The mean of each term: $$\mathbb E[q_mk_m]=\mathbb E[q_m]\,\mathbb E[k_m]=0.$$
  4. variance = second moment since mean is 0; independence again $$\operatorname{Var}(q_mk_m)=\mathbb E[q_m^2k_m^2]=\mathbb E[q_m^2]\,\mathbb E[k_m^2]=1\cdot1=1.$$
  5. terms are independent across $m$, so variances add $$\operatorname{Var}(q^\top k)=\sum_{m=1}^{d_k}\operatorname{Var}(q_mk_m)=d_k,\qquad \text{std}=\sqrt{d_k}.$$
  6. $\operatorname{Var}(X/c)=\operatorname{Var}(X)/c^2$ Choose $c=\sqrt{d_k}$: $$\operatorname{Var}\!\Big(\frac{q^\top k}{\sqrt{d_k}}\Big)=\frac{d_k}{d_k}=1,$$ independent of $d_k$.
▪

Why large scores hurt: softmax saturation step filled in — not written out in class

  1. quotient rule For $\alpha_j=e^{s_j}/\sum_re^{s_r}$: $$\frac{\partial\alpha_j}{\partial s_l}=\alpha_j(\delta_{jl}-\alpha_l),\qquad\text{i.e. }\ \frac{\partial\boldsymbol\alpha}{\partial\mathbf s}=\operatorname{diag}(\boldsymbol\alpha)-\boldsymbol\alpha\boldsymbol\alpha^\top.$$
  2. large spread of scores makes the softmax nearly one-hot If $\alpha_{j^\star}\to1$ and the rest $\to0$, every entry of the Jacobian $\to0$ (diagonal $\alpha_j(1-\alpha_j)\to0$, off-diagonal $-\alpha_j\alpha_l\to0$).
  3. chain rule The loss gradient reaching $W_Q,W_K$ passes through this Jacobian, so it vanishes: the weights stop learning which key to attend to. Large logits are also numerically unstable in $\exp$ (the lecture's "numerically poorly behaved").
▪
Worked numeric check

$d_k=64$: $\operatorname{Var}(q^\top k)=64$, std $=8$; divide by $\sqrt{64}=8$ gives std $1$. Simulation (200 000 pairs, iid $N(0,1)$ components), std of the raw score: $d_k=4\to2.00$, $16\to3.99$, $64\to8.00$, $256\to15.98$ (theory $\sqrt{d_k}=2,4,8,16$); after scaling all are $\approx1.00$. Saturation test ($d_k=64$, 10 keys, 5000 draws): unscaled mean largest weight $0.865$ and mean diagonal Jacobian $\sum_j\alpha_j(1-\alpha_j)=0.19$; scaled $0.321$ and $0.80$ — the gradient signal is about four times larger.

Remember for the exam
  • Scaling factor is $1/\sqrt{d_k}$ with $d_k$ the query/key dimension (not $d_M$ and not $d_v$).
  • Reasoning to give: dot products grow with the dimension; large logits make softmax too sharp / numerically poor with weak gradients. The one-line quantitative version is $\operatorname{Var}(q^\top k)=d_k$.
  • Always state the assumption (independent, zero mean, unit variance); it is exact at initialisation, only approximate during training.
Common mistake

Dividing by $d_k$ instead of $\sqrt{d_k}$: variance scales with the square of the divisor, so dividing by $d_k$ would give variance $1/d_k$, over-flattening the attention.

5. The causal mask enforces the autoregressive conditional

Statement

Adding $M_{ij}=0$ for $j\le i$ and $-\infty$ for $j>i$ to the scores before the softmax makes all weights on future tokens exactly zero, renormalises the weights over the allowed prefix, and (through the whole stack) makes the output at position $i$ a function of $x_1,\ldots,x_i$ only. (Oct 17 notes §13; Oct 24 §3.) Used later in: parallel teacher-forcing training (proof 12).

Proof

  1. the requirement An autoregressive model needs $p_\theta(x_t\mid x_{<t})$ not to depend on $x_{t+1},\ldots,x_T$, otherwise training would "see the answer".
  2. additive mask on the scaled scores $S_{\text{causal}}=\dfrac{QK^\top}{\sqrt{d_k}}+M$, so $s'_{ij}=s_{ij}$ for $j\le i$ and $s'_{ij}=-\infty$ for $j>i$.
  3. $\exp(-\infty)=0$ $$\alpha_{ij}=\frac{\exp(s'_{ij})}{\sum_{r=1}^{T}\exp(s'_{ir})}=0\qquad\text{for all }j>i.$$
  4. the denominator is well defined: the diagonal term $r=i$ is allowed $$\sum_{r}\exp(s'_{ir})=\sum_{r\le i}\exp(s_{ir})>0.$$
  5. renormalised softmax over the prefix For $j\le i$: $$\alpha_{ij}=\frac{\exp(s_{ij})}{\sum_{r\le i}\exp(s_{ir})},\qquad\sum_{j\le i}\alpha_{ij}=1.$$ So row $i$ is an ordinary softmax over only the allowed keys: the weights on the past are renormalised, not just truncated.
  6. sum has no future terms $$z_i=\sum_{j=1}^{T}\alpha_{ij}v_j=\sum_{j\le i}\alpha_{ij}v_j.$$
  7. $q_i,k_j,v_j$ are position-wise functions of $x_i,x_j$ only (step filled in — not written out in class) Hence $z_i$ depends only on $x_1,\ldots,x_i$. Row $1$: $\alpha_{11}=1$, so $z_1=v_1$.
  8. induction over layers (step filled in) Embedding, positional encoding, feed-forward, residual and layer norm all act on each position separately (proofs 8–10), so if layer $\ell$'s input at position $i$ depends only on $x_{\le i}$, so does its output. Therefore the final output at position $i$, which parameterises the prediction of $x_{i+1}$, depends only on $x_{\le i}=x_{<i+1}$: exactly $p_\theta(x_{i+1}\mid x_{<i+1})$. Causality holds by construction.
▪
Worked numeric check (same example as proof 3)

Scaled scores: row 1 $[0.707,0,0.707]$, row 2 $[0,0.707,0.707]$, row 3 $[0.707,0.707,1.414]$. After the mask:

  • Row 1: only $j=1$ allowed, $\alpha=[1,0,0]$, $z_1=v_1=(1,0)$.
  • Row 2: allowed scores $[0,0.707]$, $e^0=1,\ e^{0.707}=2.028$, $\alpha=[0.330,0.670,0]$, $z_2=0.330(1,0)+0.670(0,2)=(0.330,\ 1.340)$. (Unmasked row 2 gave $[0.198,0.401,0.401]$ with weight 0.401 on the future token 3.)
  • Row 3: nothing is masked, so it is unchanged: $[0.248,0.248,0.504]$, $z_3=(1.759,1.000)$.
  • Causality test: change $v_3$ to anything; $z_1,z_2$ do not change (their weight on token 3 is $0$), only $z_3$ does.
Remember for the exam
  • The mask is added before the softmax, not multiplied after. Allowed entries add $0$, forbidden ones $-\infty$; the result is a lower-triangular weight matrix.
  • The professor said "$j<i$" in class, but the diagonal is also allowed ($j\le i$): a token may attend to itself.
  • In code one uses a large negative number (for example $-10^9$) instead of a literal $-\infty$ (extra remark, same effect).
Common mistake

Zeroing the weights after the softmax: the rows would no longer sum to 1 (and the surviving weights would not be a softmax over the past). The $-\infty$ must go in before normalisation.

6. Shape bookkeeping and the quadratic cost

Statement

Attention maps a $T\times d_M$ matrix to a $T\times d_v$ matrix through a $T\times T$ weight matrix; its time and memory cost grow quadratically in the context length $T$, while the parameter count does not depend on $T$. (Oct 24 notes §2.2 for shapes; the quadratic cost from the Q&A on sliding-window and linearised attention. The explicit counts are filled in.) Used later in: why long contexts need sub-quadratic variants.

  1. projections $W_Q,W_K\in\mathbb R^{d_M\times d_k}$, $W_V\in\mathbb R^{d_M\times d_v}$, $X\in\mathbb R^{T\times d_M}$ $\Rightarrow$ $$Q,K\in\mathbb R^{T\times d_k},\qquad V\in\mathbb R^{T\times d_v}.$$
  2. $(T\times d_k)(d_k\times T)=T\times T$ $QK^\top\in\mathbb R^{T\times T}$, entry $(i,j)=q_i^\top k_j$; the row-wise softmax keeps this shape: $A\in\mathbb R^{T\times T}$.
  3. $(T\times T)(T\times d_v)=T\times d_v$ $Z=AV\in\mathbb R^{T\times d_v}$ — $T$ tokens in, $T$ tokens out.
  4. count multiply-adds $QK^\top$ needs $T^2$ dot products of length $d_k$: $T^2d_k$; $AV$: $T^2d_v$; projections: $Td_M(2d_k+d_v)$. Total $\mathcal O(T^2d+Td_Md)$ — quadratic in $T$.
  5. weights are shared across positions Parameters of one head: $d_M(2d_k+d_v)$, independent of $T$ (the model processes any length up to the context window).
▪
Worked numeric check

$d_M=512$, $d_k=d_v=64$: one head has $512\times(64+64+64)=98\,304$ parameters, whatever $T$ is. For $T=1000$: $T^2d_k=6.4\times10^7$ multiply-adds for $QK^\top$ and a $10^6$-entry weight matrix; for $T=2000$: $2.56\times10^8$ and $4\times10^6$ entries (4 times more). A sliding window of $w$ recent keys (with a KV cache) costs $T\,w\,d_k$ instead, linear in $T$, at the price of forgetting older context.

Remember for the exam
  • $d_v$ is a dimension (width of the value vectors), not a weight matrix; $d_M$ (model width) is a separate hyperparameter.
  • Vanilla attention is quadratic in context length; sliding-window / dilated / linearised attention are sub-quadratic variants (KV cache = stored past keys and values).

7. Multi-head attention: dimension split and parameter count

Statement

With $H$ heads of width $d_k=d_M/H$, the concatenated head output has width $d_M$, the total projection parameters equal those of one full-width head ($3d_M^2$), and the extra parameters come only from the mixing matrix $W_C$ ($d_M^2$). (Oct 24 notes §4: the relation $d_k=d_M/H$ and the concatenation are in class; the parameter counting is filled in.) Used later in: the full Transformer block (proof 9 onward).

  1. head $j$ (Oct 24 §4) $Q_j=XW_Q^{(j)},\ K_j=XW_K^{(j)},\ V_j=XW_V^{(j)}$ with $W^{(j)}\in\mathbb R^{d_M\times d_k}$, $$Z_j=\operatorname{softmax}\!\Big(\frac{Q_jK_j^\top}{\sqrt{d_k}}\Big)V_j\in\mathbb R^{T\times d_k},\qquad d_k=d_v=\frac{d_M}{H}.$$
  2. concatenate along the feature axis $\operatorname{Concat}(Z_1,\ldots,Z_H)\in\mathbb R^{T\times Hd_v}=\mathbb R^{T\times d_M}$, because $H\cdot\dfrac{d_M}{H}=d_M$.
  3. mix with $W_C\in\mathbb R^{d_M\times d_M}$ $Z=\operatorname{Concat}(Z_1,\ldots,Z_H)\,W_C\in\mathbb R^{T\times d_M}$: same shape as the input $X$, so the block can be stacked and wrapped in a residual connection (proof 9).
  4. block matrix multiplication (step filled in) Splitting $W_C$ into $H$ row-blocks $W_C^{(j)}\in\mathbb R^{d_v\times d_M}$: $$Z=\sum_{j=1}^{H}Z_j\,W_C^{(j)},$$ i.e. each head writes its own contribution into the shared $d_M$-dimensional output.
  5. parameter count (step filled in) Projections: $H$ heads $\times$ $3$ matrices $\times$ $d_Md_k$ $$=3H\,d_M\frac{d_M}{H}=3d_M^2,$$ exactly the count of a single head with $d_k=d_M$ ($3d_M\cdot d_M$). Adding $W_C$: $d_M^2$. Total $4d_M^2$ (ignoring biases).
  6. compute count (step filled in) Per head $T^2d_k$ for $QK^\top$; over $H$ heads $T^2Hd_k=T^2d_M$ — the same as one full-width head. Memory for weights is larger: $H$ matrices of size $T\times T$.
▪
Worked numeric check

$d_M=512$, $H=8$: $d_k=d_v=64$. Projections: $8\times3\times512\times64=786\,432=3\cdot512^2$. $W_C$: $512^2=262\,144$. Total $1\,048\,576=4\cdot512^2$. A single full-width head ($d_k=512$) has the same $786\,432$ projection parameters but only one attention pattern; 8 heads give 8 different $T\times T$ patterns for the same projection budget.

Remember for the exam
  • $d_k=d_M/H$; heads run in parallel, outputs are concatenated and mixed by $W_C$ ($=W^O$); output width stays $d_M$. $H$ is a hyperparameter; all modern Transformers use multi-head attention.
  • Professor's statement: multi-head has "more parameters than a single head because every head has its own projections and $W_C$ is added". Precisely: relative to one full-width head only the $W_C$ matrix is extra ($d_M^2$); relative to one small head of width $d_M/H$ there are $H$ times as many projections. (The class's worked example of the dimension split was garbled in the recording; only $d_k=d_M/H$ is certain.)
Common mistake

Believing each head sees only a slice of the input. Each head has its own $d_M\to d_k$ projections applied to the whole input; it is the head outputs that are placed side by side.

8. Why attention needs a position-wise feed-forward layer

Statement

For fixed attention weights, attention is linear in the token vectors, so stacking attention layers alone adds no nonlinear capacity; the position-wise MLP $\hat z_j=\sigma(z_jW_1+b_1)W_2+b_2$ supplies the nonlinearity and acts on each token separately (so it preserves causality). (Oct 24 notes §5.1: the professor stressed this verbally; the short algebraic argument is filled in.) Used later in: the full block.

  1. write attention with its weights frozen $Z=AXW_V$ where $A=\operatorname{softmax}(\cdot)$ is the weight matrix. For fixed $A$ this is linear in $X$: $Z(aX+bY)=aZ(X)+bZ(Y)$.
  2. composition of linear maps is linear Two stacked attention layers with fixed weights $A,A'$: $$Z'=A'ZW_V'=A'A\,X\,W_VW_V'=(A'A)\,X\,(W_VW_V'),$$ again of the form "mix tokens, then project": no new capacity.
  3. where nonlinearity enters attention Only through $A$, a softmax of the bilinear form $XW_QW_K^\top X^\top$; and by proof 3 the output is always a convex combination of values.
  4. position-wise MLP $\hat z_j=\sigma(z_jW_1+b_1)W_2+b_2$ with the same $W_1,b_1,W_2,b_2$ for every $j$. A one-hidden-layer network with a nonlinear $\sigma$ is a universal approximator (the lecture's remark), so per token the block can now apply a rich nonlinear map.
  5. no cross-token terms $\hat z_j$ is a function of $z_j$ alone, so the layer neither mixes positions nor leaks future information.
▪
Worked numeric check

Take $\sigma=\mathrm{ReLU}$ and a scalar token, $W_1=(1,-1)$, $b_1=0$, $W_2=(1,1)^\top$, $b_2=0$: $\hat z=\mathrm{ReLU}(z)+\mathrm{ReLU}(-z)=|z|$. Then $\hat z(2)=2$ and $\hat z(-2)=2$, but a linear map $z\mapsto cz$ would give $2c$ and $-2c$: the MLP computes a function no linear layer can.

Remember for the exam
  • "Most of the learning capacity" of the Transformer sits in the fully connected layers: all attention projections are linear and the only nonlinearity is the softmax.
  • The MLP is applied to each token separately with shared weights. The final linear layer maps to vocabulary size and the softmax there gives $p_\theta(x_t\mid x_{<t})$.

9. Residual connections and the identity gradient path

Statement

A residual block $y=x+F(x)$ can represent the identity (set $F\approx0$) and has Jacobian $I+\partial F/\partial x$, so across $L$ blocks the gradient always contains an identity term and cannot vanish multiplicatively. (Oct 24 notes §6.1: the lecture gave the identity / skip argument; the Jacobian expansion is filled in.) Used later in: the full Transformer block, where it wraps both attention and the MLP.

  1. definition $y=x+F(x)$ with $F$ the functional block (attention or MLP) and the sum applied element-wise.
  2. if the block is useless, switch it off If $F(x)\approx0$ (for example through the next layer's weights) then $y\approx x$: the block is the identity. Plain stacked layers would have to learn the identity map, which is hard; here it is the default. The architecture does not decide this; it only makes it easy to skip a block.
  3. differentiate The Jacobian is $$\frac{\partial y}{\partial x}=I+\frac{\partial F}{\partial x}=I+J.$$
  4. chain rule through $L$ blocks (step filled in) With $y_l=y_{l-1}+F_l(y_{l-1})$ and $J_l=\partial F_l/\partial y_{l-1}$: $$\frac{\partial y_L}{\partial y_0}=\prod_{l=L}^{1}(I+J_l).$$
  5. expand the product $$\prod_{l}(I+J_l)=I+\sum_lJ_l+\sum_{a>b}J_aJ_b+\cdots$$ The identity term is there for every $L$.
  6. compare with no skips Without skips $\partial y_L/\partial y_0=J_L\cdots J_1$, bounded by $c^L$ when $\|J_l\|\le c<1$ (as in proof 2). With skips the gradient reaching layer 0 is $\frac{\partial\mathcal L}{\partial y_L}\big(I+\cdots\big)$, which always contains the direct term $\frac{\partial\mathcal L}{\partial y_L}$.
▪
Worked numeric check

Scalar blocks with $J_l=0.1$ and $L=10$. Without skips: $0.1^{10}=10^{-10}$ (dead gradient). With skips: $(1+0.1)^{10}=2.59$. Even with $J_l=0$ (completely useless blocks) the gradient is exactly $1$ and the output equals the input.

Remember for the exam
  • $y=x+F(x)$; idea from ResNet. Motivation (lecture): deeper networks are not always better and can be worse; a residual makes it easy for the network to ignore a block.
  • Correction to the lecture: ResNet is from Microsoft Research (He et al., 2015), not Google.
  • In the Transformer each sub-layer (masked attention, MLP) output goes through residual + layer norm.
Common mistake

Thinking the network "decides" at run time to skip a block. It is not an explicit decision; training simply has an easy solution (small $F$) available.

10. Layer normalisation

Statement

$\operatorname{LN}(x)=\gamma\odot\dfrac{x-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta$ with $\mu,\sigma^2$ computed across the $d_M$ features of one token: the normalised vector has mean $0$ and variance $\approx1$, and the learnable $(\gamma,\beta)$ can undo the normalisation exactly. (Oct 24 notes §6.2. The lecture stated the benefits only intuitively; the algebra below is a short correct verification, not a lecture proof.) Used later in: both sub-layers of the Transformer block.

  1. statistics over the feature axis of one token $$\mu=\frac1{d_M}\sum_{i=1}^{d_M}x_i,\qquad\sigma^2=\frac1{d_M}\sum_{i=1}^{d_M}(x_i-\mu)^2.$$
  2. normalise $\hat x_i=\dfrac{x_i-\mu}{\sqrt{\sigma^2+\epsilon}}$ ($\epsilon$ avoids division by zero). Note: divide by the standard deviation, not the variance.
  3. linearity of the mean $$\frac1{d_M}\sum_i\hat x_i=\frac{\mu-\mu}{\sqrt{\sigma^2+\epsilon}}=0.$$
  4. definition of $\sigma^2$ $$\frac1{d_M}\sum_i\hat x_i^{\,2}=\frac{\sigma^2}{\sigma^2+\epsilon}\xrightarrow[\epsilon\to0]{}1.$$
  5. learnable scale and shift $\operatorname{LN}(x)_i=\gamma_i\hat x_i+\beta_i$.
  6. it can be undone Choose $\gamma_i=\sqrt{\sigma^2+\epsilon}$ ($\approx\sigma$) and $\beta_i=\mu$: $$\operatorname{LN}(x)_i=\sqrt{\sigma^2+\epsilon}\cdot\frac{x_i-\mu}{\sqrt{\sigma^2+\epsilon}}+\mu=x_i.$$ With $\gamma=1,\beta=0$ the plain normalisation is kept.
  7. extra property (not in class): invariance to scale and shift of the input For $a>0$ and $\epsilon\to0$: $x'=ax+b\mathbf 1\Rightarrow\mu'=a\mu+b,\ \sigma'=a\sigma$, so $\hat x'_i=\dfrac{a(x_i-\mu)}{a\sigma}=\hat x_i$.
▪
Worked numeric check

$x=(2,4,6,8)$: $\mu=5$, $\sigma^2=\frac{9+1+1+9}{4}=5$, $\sigma=2.236$. $\hat x=(-3,-1,1,3)/2.236=(-1.342,-0.447,0.447,1.342)$ (with $\epsilon=10^{-5}$, negligible). Mean $0$; variance $\frac{1.8+0.2+0.2+1.8}{4}=1$. Undo test: $\gamma=2.236,\beta=5$ gives back $(2,4,6,8)$.

Remember for the exam
  • Layer norm normalises across the features of each token; batch norm normalises across the batch for each feature.
  • Correction to the lecture: it said "divide by the variance" and called the pair "mu and beta"; the standard form divides by $\sqrt{\sigma^2+\epsilon}$ and the learnable pair is $(\gamma,\beta)$.
  • Why it helps was given as intuition only (not proved): like whitening / z-scoring and a regulariser so capacity is not wasted adapting to feature scales; since $\gamma,\beta$ can undo it, nothing is lost.

11. Positional encoding: why it is needed and the shift property

Statement

(a) Without positional information, self-attention is permutation-equivariant, so word order is invisible. (b) The sinusoidal encoding $\mathrm{PE}(pos,2i)=\sin(\omega_i\,pos)$, $\mathrm{PE}(pos,2i+1)=\cos(\omega_i\,pos)$ is rotated by a position-independent matrix when the position shifts by $k$. (Oct 24 notes §7 gave the need and the formula; Oct 17 §10.2 raised the order-blindness of naive models. Both derivations here are filled in.) Used later in: the first step of the block; the same idea encodes the diffusion time variable.

(a) Why position must be injected step filled in — not written out in class

  1. permute the tokens Let $P$ be a permutation matrix and feed $X'=PX$. Position-wise projections give $$Q'=PXW_Q=PQ,\qquad K'=PK,\qquad V'=PV.$$
  2. $(PQ)(PK)^\top=PQK^\top P^\top$ Scores become $S'=PSP^\top$: the same scores with rows and columns relabelled.
  3. row-wise softmax commutes with relabelling $\operatorname{softmax}(PSP^\top)=P\operatorname{softmax}(S)P^\top$, i.e. $A'=PAP^\top$.
  4. $P^\top P=I$ $$Z'=A'V'=PAP^\top PV=PAV=PZ.$$ Shuffling the input only shuffles the output in the same way: the layer cannot tell "dog bites man" from "man bites dog". The MLP, residual and layer norm are position-wise, so they do not help either. Hence order must be added to the input.
▪

(b) The shift property of the sinusoidal encoding step filled in — not written out in class

  1. define the frequencies $\omega_i=10000^{-2i/d_M}$, so the pair for dimensions $(2i,2i+1)$ is $\big(\sin\omega_ip,\ \cos\omega_ip\big)$.
  2. angle-addition formulas $$\sin(\omega p+\omega k)=\sin\omega p\cos\omega k+\cos\omega p\sin\omega k,$$ $$\cos(\omega p+\omega k)=-\sin\omega p\,\sin\omega k+\cos\omega p\cos\omega k.$$
  3. write as a matrix times the old pair $$\begin{pmatrix}\sin\omega(p+k)\\\cos\omega(p+k)\end{pmatrix}=\begin{pmatrix}\cos\omega k&\sin\omega k\\-\sin\omega k&\cos\omega k\end{pmatrix}\begin{pmatrix}\sin\omega p\\\cos\omega p\end{pmatrix}.$$ The $2\times2$ matrix is a rotation by $\omega k$ and contains no $p$.
  4. stack the $d_M/2$ pairs $\mathrm{PE}(p+k)=R_k\,\mathrm{PE}(p)$ with $R_k=\operatorname{blockdiag}\big(R(\omega_0k),\ldots,R(\omega_{d_M/2-1}k)\big)$: a fixed linear map for each offset $k$.
  5. dot product of two positions (extra) Per pair $\sin a\sin b+\cos a\cos b=\cos(a-b)$, so $$\mathrm{PE}(p)\cdot\mathrm{PE}(p+k)=\sum_{i=0}^{d_M/2-1}\cos(\omega_ik),$$ which depends only on $k$.
  6. added to the embedding (Oct 24 §7) The input to the first block is $x_t=\text{embed}(\text{token}_t)+\mathrm{PE}(t)$. The professor's reason for adding a $d_M$-dimensional vector rather than one extra scalar: a single appended coordinate in a high-dimensional vector tends to be ignored by the network.
▪
Worked numeric check

$d_M=4$: $\omega_0=1,\ \omega_1=10000^{-2/4}=0.01$. $\mathrm{PE}(1)=(\sin1,\cos1,\sin0.01,\cos0.01)=(0.8415,0.5403,0.0100,1.0000)$; $\mathrm{PE}(2)=(0.9093,-0.4161,0.0200,0.9998)$; $\mathrm{PE}(3)=(0.1411,-0.9900,0.0300,0.9996)$. Shift check for the first pair, $p=1,k=3,\omega=1$: $R(3)\,(0.8415,0.5403)^\top=(\cos3\cdot0.8415+\sin3\cdot0.5403,\ -\sin3\cdot0.8415+\cos3\cdot0.5403)=(-0.7568,-0.6536)=(\sin4,\cos4)$. Dot-product check: $\mathrm{PE}(0)\cdot\mathrm{PE}(3)=(0,1,0,1)\cdot(0.1411,-0.99,0.03,0.9996)=0.0096=\cos3+\cos0.03$.

Remember for the exam
  • Nothing else in the block (attention, MLP, norm, skip) knows the position. Sinusoids of many frequencies, even dimensions sine and odd cosine, are added to the token embeddings.
  • Formula (shown on a slide): $\mathrm{PE}(pos,2i)=\sin\!\big(pos/10000^{2i/d_M}\big)$, $\mathrm{PE}(pos,2i+1)=\cos\!\big(pos/10000^{2i/d_M}\big)$.
  • The rotation-matrix property is the textbook justification; in class only the formula and the motivation were given.

12. Maximum likelihood = sum of cross-entropies (teacher forcing)

Statement

Maximising the likelihood of the data under an autoregressive model is the same as minimising the sum over positions of the categorical cross-entropy between one-hot next-token targets and the predicted next-token distributions; with the causal mask all positions are computed in one parallel pass on the input shifted by one token (teacher forcing). (Oct 17 notes §9.3: log-likelihood and the link to KL; Oct 24 §9: loss and teacher forcing. Intermediate algebra filled in.) Used later in: pre-training and SFT of LLMs (same loss).

From likelihood to cross-entropy

  1. maximum likelihood on $N$ i.i.d. sequences $$\theta^\star=\arg\max_\theta\prod_{n=1}^{N}p_\theta\big(x^{(n)}\big)=\arg\max_\theta\sum_{n=1}^{N}\log p_\theta\big(x^{(n)}\big)\qquad(\log\text{ is monotone}).$$
  2. autoregressive factorisation (proof 1) $$\log p_\theta(x)=\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t}).$$
  3. maximise = minimise the negative The negative log-likelihood of one sequence is $$\mathcal L(\theta)=-\sum_{t}\log p_\theta(x_t\mid x_{<t}),$$ summed over the dataset in practice (the lecture's loss).
  4. one-hot target At position $t$ let $y^{(t)}\in\{0,1\}^{V}$ be the one-hot vector of the true token ($y^{(t)}_v=1$ iff $v=x_t$) and $p^{(t)}=p_\theta(\cdot\mid x_{<t})$ the model's softmax output over the vocabulary of size $V$. The categorical cross-entropy is $$H\big(y^{(t)},p^{(t)}\big)=-\sum_{v=1}^{V}y^{(t)}_v\log p^{(t)}_v=-\log p^{(t)}_{x_t},$$ because all terms except $v=x_t$ vanish.
  5. identify $$\mathcal L(\theta)=\sum_{t}H\big(y^{(t)},p^{(t)}\big):$$ the NLL of an autoregressive model is the sum of per-token cross-entropies.
  6. link to KL (lecture: "minimising a divergence such as KL") $$\mathrm{KL}(p_{\text{data}}\,\|\,p_\theta)=\mathbb E_{p_{\text{data}}}[\log p_{\text{data}}]-\mathbb E_{p_{\text{data}}}[\log p_\theta].$$ The first term does not depend on $\theta$, so minimising KL = maximising $\mathbb E_{p_{\text{data}}}\log p_\theta$, estimated by the sample average of step 1 (step filled in).
  7. gradient of the loss at the logits (extra) With $p=\operatorname{softmax}(z)$ and a one-hot $y$ at index $c$: $\ell=-z_c+\log\sum_ve^{z_v}$, so $$\frac{\partial\ell}{\partial z_v}=-\delta_{vc}+p_v=p_v-y_v.$$ The error signal is simply "predicted minus target".
▪

Teacher forcing and parallel training

  1. shift by one Input $(x_1,\ldots,x_{T-1})$, target $(x_2,\ldots,x_T)$. No external supervision is needed: the targets come from the data itself. (The very first factor $p(x_1)$ needs a start-of-sequence token; the lecture's loss runs over the shifted positions.)
  2. the context for every factor is the true past, known at training time To evaluate $p_\theta(x_t\mid x_{<t})$ for every $t$ we do not have to generate anything; the whole sequence is already available ("the teacher forces the correct past").
  3. causal mask (proof 5) Position $i$ of the output depends only on $x_{\le i}$, so the single forward pass computes all $T-1$ conditionals at once and none of them sees its own target.
  4. ordinary empirical risk minimisation Sum the cross-entropies and backpropagate: standard gradient descent on $\theta$ (lecture homework: derive the gradients of the loss with respect to $W_Q,W_K,W_V$ by hand — easy because the projections are linear).
▪
Worked numeric check

Three predictions with the true tokens given probabilities $0.5,\ 0.25,\ 0.5$. Cross-entropies: $-\ln0.5=0.693$, $-\ln0.25=1.386$, $-\ln0.5=0.693$; $\mathcal L=2.773$. Check via the joint: $0.5\cdot0.25\cdot0.5=1/16$ and $-\ln(1/16)=\ln16=2.773$. Gradient at the logits for the second position (vocabulary of 4, true token index 2): $p-y$ has entry $0.25-1=-0.75$ at the true token and positive entries on the others summing to $+0.75$ (gradients sum to zero).

Remember for the exam
  • Loss $\mathcal L(\theta)=-\sum_t\log p_\theta(x_t\mid x_{<t})$ = categorical cross-entropy; pre-training uses it on unlabelled text (targets = shifted input); SFT uses the same loss on $(x,y)$ pairs where the target tokens are the response $y$.
  • Teacher forcing: target = input shifted by one token, no external supervision; maximum likelihood is linked to minimising KL between data and model.
  • It is gradient descent on the loss (ascent on the log-likelihood).
Common mistake

Treating the one-hot cross-entropy as a different loss from the NLL. They are identical: the one-hot target kills every term except $-\log p(x_t\mid x_{<t})$.

13. Inference: sequential decoding and temperature

Statement

Generation applies the chain rule in reverse (one token per forward pass, each conditioned on what has been generated, proof 1). Temperature rescaling $\operatorname{softmax}(z/\tau)$ sharpens the distribution for $\tau<1$ (greedy as $\tau\to0$) and flattens it for $\tau>1$ (uniform as $\tau\to\infty$); top-$K$ and top-$P$ truncate and renormalise. (Oct 24 notes §10 gave the list of rules; the limits below are filled in.) Used later in: using LLMs after training.

Why inference is sequential and exact

  1. chain rule (proof 1) $p_\theta(x)=\prod_tp_\theta(x_t\mid x_{<t})$, so ancestral sampling of $x_t$ from $p_\theta(\cdot\mid x_{<t})$ for $t=1,2,\ldots$ draws exact samples of the joint.
  2. $x_t$ must be known before computing step $t+1$ The context of factor $t+1$ contains the token just generated, so passes cannot run in parallel: $T$ tokens cost $T$ passes. (Storing past keys and values, the "KV cache", avoids recomputing them; sliding-window attention discards old ones.)
  3. stop Generation ends when the end-of-sequence token is produced.
▪

Temperature step filled in — not written out in class

  1. definition (lecture: divide the logits by $\tau$ before the softmax) $$p_v^{(\tau)}=\frac{e^{z_v/\tau}}{\sum_{u}e^{z_u/\tau}}.$$ $\tau=1$ is the model's own distribution.
  2. ranking is preserved, log-ratios scaled $$\frac{p_u^{(\tau)}}{p_v^{(\tau)}}=\exp\!\Big(\frac{z_u-z_v}{\tau}\Big):$$ the order of tokens never changes, but small $\tau$ stretches the gaps and large $\tau$ shrinks them.
  3. $\tau\to0^+$: divide numerator and denominator by $e^{z_{\max}/\tau}$ $$p_v^{(\tau)}=\frac{e^{(z_v-z_{\max})/\tau}}{\sum_ue^{(z_u-z_{\max})/\tau}}\to\begin{cases}1&v=\arg\max\ (\text{unique})\\0&\text{otherwise,}\end{cases}$$ because $z_v-z_{\max}<0$ makes the exponent $\to-\infty$ — greedy decoding.
  4. $\tau\to\infty$ $z_v/\tau\to0$ for all $v$, so $p_v^{(\tau)}\to e^0/\sum_ue^0=1/V$: the uniform distribution.
▪

Top-K and top-P are renormalised truncations

  1. top-$K$ Let $\mathcal K$ be the $K$ most probable tokens; $p'_v=p_v\big/\sum_{u\in\mathcal K}p_u$ for $v\in\mathcal K$, $0$ otherwise. This sums to $1$ by construction.
  2. top-$P$ (nucleus) Take the smallest set $\mathcal N$ of top-ranked tokens with $\sum_{u\in\mathcal N}p_u\ge P$, then renormalise in the same way. The set size adapts to the confidence of the model (a peaked distribution keeps few tokens, a flat one many).
▪
Worked numeric check

Logits $z=(2,1,0)$ for tokens $a,b,c$. $\tau=1$: $(0.665,0.245,0.090)$. $\tau=0.5$: $z/\tau=(4,2,0)$, $e^{(4,2,0)}=(54.60,7.39,1)$, sum $62.99$, giving $(0.867,0.117,0.016)$ — sharper. $\tau=2$: $e^{(1,0.5,0)}=(2.718,1.649,1)$, sum $5.367$, giving $(0.507,0.307,0.186)$ — flatter. $\tau=100$: $(0.337,0.333,0.330)\approx$ uniform. Top-2 on the $\tau=1$ distribution: $0.665/0.910=0.731$ and $0.245/0.910=0.269$. Top-$P$ with $P=0.8$: $a$ alone has $0.665<0.8$, $a+b=0.910\ge0.8$, so the nucleus is $\{a,b\}$ and the renormalised result is the same $(0.731,0.269)$.

Remember for the exam
  • Greedy = argmax each step; vanilla (ancestral) sampling = sample the full softmax; top-$K$ = keep $K$ best, renormalise, sample; top-$P$ = smallest set with cumulative probability $\ge P$ (nucleus), renormalise, sample (widely used); temperature divides the logits: high $\tau$ flatter, low $\tau$ sharper.
  • Training is parallel (one pass, teacher forcing); generation is sequential (one pass per token).
Common mistake

Applying temperature to the probabilities instead of the logits, or forgetting to renormalise after top-$K$ / top-$P$ truncation.
